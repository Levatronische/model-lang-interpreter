# Интерпретатор модельного языка

Интерпретатор учебного языка на C++17, практикум ВМК МГУ. Программа проходит полный путь: лексический анализ, синтаксический и семантический анализ, генерация ПОЛИЗ (обратной польской записи) и выполнение на стековой машине.

## Язык

- типы `int`, `real`, `string`, объявления с инициализацией
- `if` / `else`, `while`, `for`, `break`, `goto` и метки
- `read`, `write`
- арифметика, сравнения, `&&`, `||`
- комментарии `/* ... */`

```
program
int i = 0, sum = 0, n;
read(n);
while (i <= n) {
    sum = sum + i;
    i = i + 1;
}
write(sum);
```

Больше в [`examples/sum.txt`](examples/sum.txt).

## Устройство

Проект собирался по этапам, каждый файл самостоятельная программа:

| Файл | Этап |
|------|------|
| `la.cpp` | лексический анализатор |
| `sa.cpp` | синтаксический анализ рекурсивным спуском, таблица символов, проверка типов и объявлений |
| `pl.cpp` | генерация ПОЛИЗ |
| `itr.cpp` | полный интерпретатор: всё выше плюс стековая машина на `std::variant` |

Ошибки выводятся с типом (лексическая, синтаксическая, семантическая, выполнения), строкой и столбцом.

## Сборка и запуск

```sh
make            # собирает itr
cp examples/sum.txt input.txt
echo 5 | ./itr  # программа читается из input.txt
```

Вывод: ПОЛИЗ программы и результат выполнения.
